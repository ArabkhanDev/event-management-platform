# auda

Live event-engagement platform: Q&A, keypad voting, surveys, presentation
control and a live stage screen for conferences and congresses.

This is a monorepo with two independently deployable apps:

- [`backend/`](backend/) — Spring Boot 3.3.4 / Java 21 API + WebSocket (STOMP/SockJS). See [backend/README.md](backend/README.md).
- [`frontend/`](frontend/) — React + TypeScript + Vite. See [frontend/README.md](frontend/README.md).

Each has its own README with setup and run instructions.
